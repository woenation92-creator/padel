# Бот «Грань: расписание»

Telegram-бот: присылаешь подложку (картинку) и дату → бот сам заходит
на сайт клуба headless-браузером, забирает свободные часы и отдаёт ту
же картинку с наложенным расписанием, готовую для поста или сторис.

Всё в этой инструкции можно сделать **с телефона, без компьютера и
без терминала** — и первую настройку, и дальнейшее использование.

## Как это выглядит для пользователя

1. Отправляете боту картинку-подложку — или выбираете готовую из
   встроенной библиотеки командой `/template <номер>` (см. `/menu`),
   если не хотите присылать своё фото.
2. Бот спрашивает: «На какую дату?» и показывает кнопки **Сегодня /
   Завтра / Послезавтра** — жмёте нужную, либо просто печатаете дату
   текстом, если нужна другая.
3. Бот сам открывает granpadel.ru/book в headless-браузере, забирает
   расписание и присылает готовую картинку с оформленными свободными
   часами — в фирменных цветах клуба.
4. Если сайт вдруг не ответил — бот сам попросит вписать часы текстом,
   как запасной вариант, и всё равно соберёт картинку.

### Готовые логотипы, шрифты и подложки — без загрузки файлов

Команда **`/menu`** показывает пронумерованный список того, что уже
встроено в бота:

- `/logo <номер>` — переключить логотип (несколько готовых вариантов
  на тёмный/светлый фон).
- `/font <номер>` — переключить шрифт текста на карточке.
- `/template <номер>` — использовать готовую подложку вместо своего
  фото.

Если нужен свой файл — можно прислать его напрямую, документом с
подписью-командой в том же сообщении: `/set_logo`, `/set_font_bold`,
`/set_font_medium`, `/set_font_italic`. Команда `/reset_assets`
возвращает всё к настройкам по умолчанию.

## Часть 1. Настройка — с телефона, один раз

Понадобится только браузер на телефоне (Safari/Chrome) и приложение
Telegram. Всего два шага: закинуть код на GitHub → подключить его к
Railway (сервис, который будет держать бота включённым круглосуточно).

### Шаг 1. Получить токен бота

1. Откройте Telegram, найдите **@BotFather**.
2. Напишите `/newbot`, следуйте подсказкам (придумайте имя бота).
3. BotFather пришлёт токен вида `123456789:AAExampleToken...` —
   скопируйте его, он понадобится в шаге 3.

### Шаг 2. Выложить код на GitHub

1. Скачайте на телефон файл `schedule_bot.zip`, который я прислал.
2. Распакуйте его через приложение **Файлы** (iPhone) или
   **Файлы**/диспетчер файлов (Android) — оба умеют разархивировать
   zip без дополнительных приложений.
3. Откройте **github.com** в браузере телефона, войдите или
   зарегистрируйтесь.
4. Нажмите **+** → **New repository**. Назовите, например,
   `granpadel-schedule-bot`. Сделайте его **Private** (это ваш бот,
   чужим видеть код не нужно). Создайте репозиторий.
5. На странице репозитория нажмите **Add file** → **Upload files**.
6. Откройте выбор файлов и **выделите все файлы разом** (кнопка
   «выбрать всё» или долгий тап + отметить остальные) — их 21 штука,
   все в одной папке без вложенных подпапок, чтобы загрузка с телефона
   прошла без проблем с иерархией.
7. Внизу нажмите **Commit changes**.

### Шаг 3. Подключить Railway и запустить бота

1. Откройте **railway.app** в браузере телефона, войдите через GitHub
   (кнопка «Login with GitHub» — так Railway сразу увидит ваш
   репозиторий).
2. **New Project** → **Deploy from GitHub repo** → выберите
   `granpadel-schedule-bot`.
3. Railway сам увидит `Dockerfile` в репозитории и соберёт всё
   нужное — Python, зависимости, браузер для Playwright. Ничего
   ставить руками не нужно, это займёт пару минут.
4. Зайдите в настройки проекта → вкладка **Variables** → добавьте
   переменную:
   - имя: `BOT_TOKEN`
   - значение: токен, который дал BotFather в шаге 1.
5. Дождитесь, пока статус деплоя станет **Success** (обычно 2-5
   минут).

Готово — бот работает и будет работать постоянно, даже если вы
закроете телефон. Откройте Telegram, найдите своего бота, нажмите
**Start**.

## Часть 2. Калибровка — тоже с телефона, через сам Telegram

Я написал и проверил весь код, но не смог протестировать его именно
против вашего живого сайта: из моей рабочей среды сеть идёт через
прокси, который блокирует обращения к незаявленным заранее хостам.
Поэтому точную структуру ответа вашего сайта нужно один раз сверить —
и это тоже делается прямо из Telegram, без компьютера.

1. Напишите своему боту: **`/debug 24 сентября`** (или любая другая
   дата).
2. Бот сходит на сайт и ответит одним из двух способов:
   - **Пришлёт список часов** — отлично, всё заработало само,
     калибровка не нужна, дальше просто пользуйтесь ботом как обычно.
   - **Напишет «ничего не нашёл» и пришлёт файл** —
     `debug_schedule_capture.json`. Это сырые данные, которые бот
     подсмотрел на сайте.
3. Если пришёл файл — перешлите его мне в чат (или откройте новый
   разговор с Клодом и прикрепите этот файл), напишите: «вот что
   поймал бот, поправь разбор под это» — я по нему сразу напишу
   точный код для `schedule.py`, останется только вставить его через
   веб-редактор GitHub (тоже с телефона: в репозитории откройте
   `schedule.py` → значок карандаша **Edit** → вставьте новый код →
   **Commit changes**). Railway сам передеплоит бота после коммита.

После этого `/debug` снова — чтобы убедиться, что теперь часы
находятся. Дальше калибровка не нужна, бот работает сам.

## Структура проекта

schedule_bot/

├── schedule.py                  — headless-браузер, который сам забирает расписание с сайта
├── library.py                   — пронумерованное меню готовых логотипов/шрифтов/подложек
├── DejaVuSans.ttf                — шрифт 1 (обычный)
├── DejaVuSans-Bold.ttf           — шрифт 1 (жирный, для заголовка)

├── font2_Lora-Bold.ttf           — шрифт 2 (жирный)
├── font2_Lora-BoldItalic.ttf     — шрифт 2 (жирный курсив)
├── logo_1_white.png              — логотип, вариант 1
├── logo_2_lime_cream.png         — логотип, вариант 2
├── logo_3_lime_dark.png          — логотип, вариант 3
├── logo_4_icon_only.png          — логотип, вариант 4
├── template_1_coffee.jpg         — готовая подложка, вариант 1
├── template_2_action.jpg         — готовая подложка, вариант 2

Все файлы — в корне, без подпапок. Это специально: при загрузке на
GitHub с телефона (см. часть B ниже) можно выделить их все разом одним
движением, без навигации по вложенным папкам, которая на мобильном
браузере часто работает нестабильно.

## Как это работает технически

- **bot.py** — построен на библиотеке `aiogram` (асинхронный фреймворк
  для Telegram-ботов). Ведёт пользователя по шагам: ждёт фото → ждёт
  дату → сам получает расписание → собирает и отправляет картинку.
  Команда `/debug <дата>` — служебная, для калибровки прямо из чата.
- **image_composer.py** — открывает присланную подложку через Pillow,
  рисует полупрозрачную карточку в фирменном зелёном цвете с сеткой
  свободных часов поверх. Вся геометрия считается в долях от размера
  картинки, поэтому одинаково хорошо работает и на сторис (1080×1920),
  и на квадратном посте (1080×1080), и на любом другом размере.
- **schedule.py** — открывает `granpadel.ru/book` в headless Chromium
  через Playwright, слушает все сетевые ответы страницы, находит среди
  них похожий на расписание JSON и вытаскивает из него свободные часы.
  Если по сети ничего подходящего не нашлось — пробует вытащить времена
  из отрендеренного текста страницы. Если и это не сработало —
  возвращает `None`, и бот запасным вариантом спрашивает человека.
- **library.py** — список готовых логотипов/шрифтов/подложек с
  номерами для команд `/logo`, `/font`, `/template`. Команды в
  bot.py при выборе номера просто копируют нужный файл поверх
  `assets/logo.png` (или `font_bold.ttf` и т.д.) — ровно туда же,
  куда кладутся и файлы, загруженные вручную через `/set_logo` и
  похожие команды. Оба способа выбора равнозначны и используют один
  и тот же механизм.
- **Dockerfile** — по нему Railway/Render сами соберут окружение:
  поставят Python, зависимости и браузер Chromium. Без него пришлось
  бы вручную набирать команды установки в терминале — с Dockerfile
  это не нужно.

## Изменить стиль карточки с расписанием

Всё оформление — в файле `image_composer.py`:

- `DEEP_GREEN`, `LIME`, `CREAM` — фирменные цвета клуба, при желании
  замените на другие HEX-коды. Менять можно прямо в веб-редакторе
  GitHub с телефона.
- Шрифты — сейчас DejaVu Sans (гарантированно поддерживает кириллицу).
  Если захотите визуально более близкий к Poppins (как в остальных
  материалах клуба) шрифт — учтите, что обычный Poppins с Google
  Fonts **не поддерживает кириллицу**, и русский текст превратится в
  квадраты. Нужна версия с добавленной кириллицей.
- Текст заголовка `"СВОБОДНЫЕ ЧАСЫ"` — меняется прямо в
  `compose_schedule_image()`.

После любого изменения файла на GitHub через веб-редактор — просто
нажмите **Commit changes**, Railway сам пересоберёт и перезапустит
бота, руками ничего перезапускать не нужно.

## Ограничения текущей версии

- Требует один раз откалибровать разбор JSON под реальный сайт (см.
  «Часть 2» выше) — без этого шага бот будет уходить в запасной
  ручной ввод при каждом запросе.
- Если на сайте есть отдельная логика для тренировок с занятыми/
  свободными местами (например, «Участники: 2/4») и обычных слотов
  аренды корта отдельно — текущая версия сначала просто собирает все
  времена под одну гребёнку. Различать типы слотов — доработка функции
  `_extract_free_slots()` в `schedule.py`.
- Обрабатывается один запрос за раз на каждого пользователя — для
  одного SMM-менеджера/фотографа этого достаточно.
- Если свободных часов очень много (15+), часть может не поместиться
  на карточке — код обрезает лишнее, чтобы не вылезти за подложку.
